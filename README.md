# Miraj & Partner – Store Website

One-page catalogue website for Miraj & Partner (sanitary, electrical, drainage, plumbing, hardware, paint, general items, steel and cement).

- Open `index.html` in a browser to view the site. No build step.
- To edit store info, categories or products, change the marked section at the top of the `<script>` in `index.html` (between "EDIT THIS SECTION" and "END EDIT SECTION").
- Product photos are embedded in the file as data URIs (the `IMG`, `DIMG`, `EIMG`, `EIMG2`, `NIMG`, `SIMG`, `SIMG2` blocks).
